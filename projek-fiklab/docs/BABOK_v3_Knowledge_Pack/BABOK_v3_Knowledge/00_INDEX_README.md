## How the BABOK® Guide is organized

- **Key concepts** (Ch. 2): the Business Analysis Core Concept Model™ (BACCM) — Change, Need, Solution, Stakeholder, Value, Context.
- **6 Knowledge Areas** (Ch. 3–8) containing **30 tasks**. Every task has the same anatomy: .1 Purpose, .2 Description, .3 Inputs, .4 Elements, .5 Guidelines and Tools, .6 Techniques, .7 Stakeholders, .8 Outputs.
- **Underlying Competencies** (Ch. 9), **50 Techniques** (Ch. 10: Purpose, Description, Elements, Usage Considerations), **5 Perspectives** (Ch. 11: Agile, BI, IT, Business Architecture, BPM).

## Conversion notes (what was changed from the raw PDF→Markdown)

- Removed page numbers, running headers/footers, table of contents and the page-number index; kept printed page numbers at every section heading (`p. N`) for citation.
- Rebuilt heading hierarchy: Chapter (#) → Section/Task/Technique (##) → numbered subsection (###) → element (####). Subsection headings carry their parent name (e.g. "3.1.4 Elements — Plan Business Analysis Approach") so each retrieved chunk is self-describing.
- Re-joined sentences that were split by page breaks or figures; normalized ®/™ markup and table cell line breaks.
- Figures: captions kept; text inside diagrams kept as "Diagram labels" (layout cannot be preserved in text). Input/Output diagrams were replaced by a generated **Task Summary Card** at the top of each task.
- Appendix B (Techniques to Task Mapping) was unreadable after conversion and has been regenerated — see `B_Techniques_to_Task_Mapping_REBUILT.md`.
- Not included: Appendix C (list of contributor names), the back-of-book index, copyright/trademark front matter.
